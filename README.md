# On Task Pre-Print (Chapter 3)
This repository contains the scripts needed for on-task processing of the submarine simulation EEG data, presented in the online preprint published on BioRXIv: https://www.biorxiv.org/content/10.1101/2024.07.29.605541v1

Scripts Included:
* on-task-IRASA.py             Pre-processing of on-task EEG data to extract 1/f and power measures across time
* pre-processing-on-task.py    Filtering and general pre-processing of data before extracting relevant power measures and ERP epochs.
* solution_RP_script.py        Using epochs, script extracts windows and time information for the creation of grand average plots.
